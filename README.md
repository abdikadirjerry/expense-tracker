# Vanilla JS Expense Tracker

A clean, responsive, feature-complete Expense Tracker web application built from scratch using Vanilla JavaScript (ES6+), HTML5, and CSS3. 

---

## Features

- **Real-Time Financial Summary:** Automatically calculates total balance, total income, and total expenses dynamically.
- **Transaction History:** Scrollable list of past transactions with visual indicators (green for income, red for expense).
- **Interactive Forms:** Input validation for description and monetary amounts (positive for income, negative for expenses).
- **Deletion Capability:** Easily remove any transaction with hover-triggered delete buttons.
- **Persistent Storage:** Fully integrated with browser `localStorage` so your data persists across page reloads.
